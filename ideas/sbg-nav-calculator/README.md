# SBG NAV Official / Live v3

公式NAVと手入力シナリオを比較する静的Webアプリ。実際に使用するHTML・CSS・JavaScriptはindex.htmlに集約しています。

## 起動・確認

公開URL: https://git333-20260310.github.io/Idea-Sandbox/ideas/sbg-nav-calculator/

ローカル: このフォルダで `python3 -m http.server 5173` を実行して http://localhost:5173/ を開きます。

## 公式基準

確認日2026-10-10。最新公表四半期は2026-06-30（2026-08-06公表）。出典: https://group.softbank/ir/stock/sotp

- 保有株式価値（アセットバック・ファイナンス調整後）83.11兆円
- 調整後純負債10.81兆円
- NAV72.30兆円、LTV13.0%
- 自己株式を除く株数5,699百万株。丸め済み公表値から1株NAV約12,686円を計算
- 基準株価5,963円、USD/JPY162.39
- Arm49.91、SVF1 3.60、SVF2 19.29、LatAm1.00、SBKK2.79、T-Mobile0.00、その他6.51兆円。内訳合計83.10と公表合計83.11の差は丸め差。計算は公表合計を優先

公式カードは固定。下段は資産価値の差分と将来枠の差分を加算して試算用負債を控除し、試算用株数で割ります。初期状態では上下が一致します。

SBG株価・為替のみStooqの最新利用可能な終値を取得できます（非公式参考値、ブラウザのCORS制約等で失敗時は入力値を維持）。旧保有株数で不正確な換算をしないため、資産価値は各枠全体を手入力します。

将来枠は全て初期OFF・評価額未設定。既存投資を再評価する場合は、公式計上済み価値を必ず入力し差分だけ加算します。追加投資の資金調達・現金減少等も試算用純負債に反映してください。

## 確認方法

1. 初期表示は公式・試算とも72.30兆円、約12,686円。公式LTV13.0%。
2. 純負債を10810から11810へ変更すると試算NAVは71.30兆円。公式カードは固定。
3. Armの現在価値を1兆円増やすと試算NAVが1兆円増加。
4. 将来枠は想定持分価値から公式計上済み価値を控除。
